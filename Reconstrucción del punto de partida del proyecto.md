
## Reconstrucción del punto de partida del proyecto  

Duración: 3 horas  
Modalidad: 2 horas autónomas + 1 hora presencial  
Producto: Matriz diagnóstica de continuidad y recuperación  
Evaluación: diagnóstica y formativa, sin calificación sumativa  
 
### Propósito

Reconstruir, a partir de la memoria del equipo y de las evidencias disponibles, el estado actual del proyecto desarrollado en TDTA I–II

Al terminar la actividad, cada equipo deberá poder explicar:

* Qué problema intentaron resolver.
* Qué proceso o planta analizaron.
* Qué solución de automatización imaginaron.
* Qué actividades alcanzaron a realizar.
* Qué decisiones tomaron.
* Qué información pueden demostrar.
* Qué información deberán reconstruir durante TDTA III.


# Trabajo autónomo — 2 horas

## 1. Recuperar lo que realmente se hizo — 25 minutos

Antes de elaborar documentos nuevos, el equipo reunirá cualquier evidencia disponible, aunque esté incompleta o dispersa:

* Presentaciones.
* Reportes.
* Fotografías o videos.
* Diagramas.
* Bocetos.
* Programas o simulaciones.
* Cálculos.
* Investigaciones.
* Cotizaciones.
* Mensajes o acuerdos del equipo.
* Retroalimentación de profesores.
* Archivos individuales.
* Enlaces o referencias consultadas.

## 2. Reconstruir la historia del proyecto — 25 minutos

El equipo elaborará una línea de tiempo sencilla:

| Momento            | ¿Qué hicieron?                | ¿Qué decidieron?        | ¿Qué resultado obtuvieron?   | Evidencia disponible                      |
| ------------------ | ----------------------------- | ----------------------- | ---------------------------- | ----------------------------------------- |
| TDTA I             | Identificamos un problema en… | Elegimos trabajar con…  | Se propuso automatizar…      | Presentación, fotografía o sin evidencia  |
| TDTA II            | Investigamos…                 | Seleccionamos…          | Se elaboró…                  | Reporte, diagrama, código o sin evidencia |
| Inicio de TDTA III | Actualmente sabemos que…      | Está pendiente decidir… | El proyecto se encuentra en… | Evidencia actual                          |

Si no recuerdas una decisión, deben escribir “No identificado” en lugar de inventarla.

## 3. Elaborar la ficha de reconstrucción — 40 minutos

Cada equipo responderá con la información que tenga:

### A. Situación o necesidad

* ¿Qué situación observaron?
* ¿A quién afecta?
* ¿Dónde ocurre?
* ¿Qué consecuencia produce?
* ¿Por qué consideraron que podía resolverse mediante automatización?

### B. Proceso y planta

* ¿Qué proceso pretendían modificar, controlar o supervisar?
* ¿Cuál es la entrada del proceso?
* ¿Qué transformación ocurre?
* ¿Cuál es la salida?
* ¿Qué equipo, instalación o entorno físico constituye la planta?
* ¿Qué variables identificaron?

### C. Propuesta de automatización

* ¿Qué función debía realizar el sistema?
* ¿Qué pensaban medir?
* ¿Qué pensaban controlar o accionar?
* ¿Qué información debía procesarse?
* ¿Cómo interactuaría el usuario?
* ¿Qué componentes consideraron utilizar?

### D. Estado actual

* ¿Qué parte se encuentra definida?
* ¿Qué parte solamente es una idea?
* ¿Qué parte se investigó?
* ¿Qué parte se diseñó?
* ¿Existe alguna simulación, programa, circuito o prueba?
* ¿Qué decisiones siguen pendientes?

## 4. Elaborar la matriz diagnóstica — 30 minutos

La matriz deberá ser sencilla y no presuponer productos anteriores.

| Elemento                      | Lo que el equipo sabe actualmente | Evidencia disponible | Nivel de claridad             | Qué necesita recuperarse o definirse |
| ----------------------------- | --------------------------------- | -------------------- | ----------------------------- | ------------------------------------ |
| Problema                      |                                   |                      | Claro / Parcial / No definido |                                      |
| Usuarios o afectados          |                                   |                      | Claro / Parcial / No definido |                                      |
| Proceso                       |                                   |                      | Claro / Parcial / No definido |                                      |
| Planta                        |                                   |                      | Claro / Parcial / No definido |                                      |
| Variables                     |                                   |                      | Claro / Parcial / No definido |                                      |
| Oportunidad de automatización |                                   |                      | Claro / Parcial / No definido |                                      |
| Funciones del sistema         |                                   |                      | Claro / Parcial / No definido |                                      |
| Sensores considerados         |                                   |                      | Claro / Parcial / No definido |                                      |
| Actuadores considerados       |                                   |                      | Claro / Parcial / No definido |                                      |
| Controlador o procesamiento   |                                   |                      | Claro / Parcial / No definido |                                      |
| Interfaz o supervisión        |                                   |                      | Claro / Parcial / No definido |                                      |
| Seguridad y riesgos           |                                   |                      | Claro / Parcial / No definido |                                      |
| Restricciones                 |                                   |                      | Claro / Parcial / No definido |                                      |
| Avances realizados            |                                   |                      | Claro / Parcial / No definido |                                      |
| Pendientes principales        |                                   |                      | Claro / Parcial / No definido |                                      |

En “Evidencia disponible” pueden utilizar:

* Documento.
* Fotografía.
* Diagrama.
* Código.
* Simulación.
* Explicación coincidente del equipo.
* Sin evidencia.

La explicación coincidente del equipo es válida como punto de partida, pero se deberá convertir posteriormente en información verificable.
